# About

Welcome to **RazzSec Lab**, my personal security notebook and CTF archive.

I use this site to document what I learn while solving challenges, building tools, breaking binaries, debugging Linux boxes, and studying real attack paths. The goal is simple: write clear notes that future me can reuse, and that other learners can follow without guessing the missing steps.

## Focus Areas

- **Linux:** privilege escalation, services, enumeration, shell workflow, hardening notes
- **Reverse Engineering:** Ghidra, strings, patching, anti-debugging, control flow recovery
- **Binary Exploitation:** stack overflows, ret2win, ROP, format strings, heap basics
- **Web Security:** auth bugs, IDOR, SSRF, injection, file upload, request smuggling notes
- **Forensics:** memory, packet captures, disk images, logs, timeline analysis
- **Projects:** scripts, exploit templates, automation, and small security tools

## Writeup Format

Most writeups follow this structure:

1. Challenge summary
2. Recon and observations
3. Vulnerability or core idea
4. Exploitation steps
5. Flag or result
6. Lessons learned

::tip
Spoilers are expected in CTF writeups. I try to explain the reasoning, not just paste the final command.
::
