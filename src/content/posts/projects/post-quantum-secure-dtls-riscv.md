## Overview

This project explored securing IoT communication by integrating post-quantum cryptographic key exchange into **DTLS 1.3** and testing it in a constrained RISC-V environment.

## Key Work

- Implemented **DTLS 1.3** with post-quantum cryptographic key exchange
- Integrated PQC algorithms into the DTLS handshake
- Evaluated compatibility and performance on resource-constrained systems
- Deployed and tested the implementation on a **RISC-V LiteX-based SoC simulation**
- Focused on embedded security constraints, protocol behavior, and performance tradeoffs

## Result

This work contributed to an **Inter IIT Tech Meet 14.0** project where the team ranked **5th** in PQC implementation and DTLS protocol work.
